# Start point

The original inputs the project was started from, kept verbatim for
traceability. Requirements may cite files here as their `source`
(REQUIREMENTS-MANAGEMENT.md §8).

Put here:

- `goal.txt` (or `.md`) — the initial brief, as the user wrote it.
- External contracts — interface headers/schemas or requirement documents
  from consumers of this project, in a subfolder per consumer.
- Any other founding material (specs snapshots, decisions from kickoff).

Do not edit these files after adding them; record changed expectations as new
or superseding requirements instead.
