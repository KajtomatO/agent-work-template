# Contributing

- **Git rules** (humans and agents): [AGENTS.md](AGENTS.md) §1 and
  [docs/GIT-WORKFLOW.md](docs/GIT-WORKFLOW.md). Work on a branch created from
  `development`; pull requests target `development`.
- **How work is tracked** (requirements, steps, traceability):
  [REQUIREMENTS-MANAGEMENT.md](REQUIREMENTS-MANAGEMENT.md).
- **Before opening a pull request:** run `./dev ci` and fill in the PR template.
